# 抖音本地视频制作 V0.3

个人本地 Android 工具，不需要服务器。

## V0.3 核心流程

**选择截图 → 裁剪 → 加文字 → 选音乐 → 设置时长 → 选择 1080P/4K → 生成视频**

### 输出规格
- 1080P：1080 × 1920，9:16，MP4，H.264 + AAC，30fps（默认推荐）
- 4K：2160 × 3840，9:16，MP4，H.264 + AAC，30fps
- 视频时长：0.7～15 秒，自定义输入，默认 0.7 秒

> 注意：4K 编码依赖手机硬件编码器。部分低端/较老机型可能无法输出 2160×3840；遇到失败请改用 1080P。

## 使用方法
1. 在抖音商品页把包含券后价、规格、数量等需要的信息系统截图。
2. 打开 APP，点“选择截图”。
3. 裁剪保留商品/价格区域。
4. 输入文字或选择已保存模板；在预览画面上拖动文字位置。
5. 选择音乐；音乐可从音乐库导入音频或带音轨视频。
6. 设置视频时长，选择 1080P 或 4K。
7. 点“生成视频并保存到相册”。
8. 成品保存到 `Movies/DouyinLocalMaker`。

## 云编译
项目自带 `.github/workflows/build-apk.yml`。上传/替换到 GitHub 仓库后，Actions 会自动构建 APK。
