# 抖音本地截图视频工具 V0.4

个人本地使用，不需要服务器。

## 使用流程
选择截图 → 裁剪 → 加文字 → 选音乐（可选） → 设置时长 → 选择1080P/4K → 生成视频

## V0.4 修复
- 修复部分安卓手机导入相册截图后提示 `Software rendering doesn't support hardware bitmaps`
- 导入图片强制使用软件 Bitmap，裁剪与合成阶段再次兜底转换
- 字体颜色可选：红 / 白 / 黄 / 绿 / 蓝，默认红色
- 文字模板会保存字体颜色
- 不选择音乐也可以直接生成并保存视频
- 默认 1080P 1080×1920；可切换 4K 2160×3840
- 输出 MP4，H.264，30fps
