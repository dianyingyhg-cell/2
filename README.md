# DouyinLocalMaker V0.2

个人本地使用的 Android 商品截图短视频制作工具。**不需要服务器、不需要账号系统，图片、模板、音乐和生成的视频都在手机本地处理。**

## V0.2 新增

- 截图后进入裁剪器，可拖动裁剪框，也可拖四个白色角点改变大小。
- 自动记住上一次裁剪区域（使用归一化坐标保存）。
- 新增“快速截(上次区域)”：同类商品页可以直接复用上一次区域，不必重复框选。
- 新增“重新裁剪”：当前素材可重新调整区域。
- 相册导入图片后同样先进入裁剪器。
- 默认裁剪区域优先按 9:16 居中，方便竖屏短视频。

## 主要流程

1. 复制商品链接。
2. APP 内粘贴并打开商品页。
3. 滚动到需要的商品画面。
4. 第一次点“截图并裁剪”，手动选择区域并保存。
5. 后续同类页面可以直接点“快速截(上次区域)”。
6. 输入文字，或选择已经保存的文字模板。
7. 在预览画面里拖动文字位置，调整字号和角度。
8. 从本地音乐库选择你自己提供的音频/带音轨视频。
9. 设置 0.7～15 秒视频时长。
10. 点“生成 MP4 并保存到相册”。

## 本地数据

- 文字模板：SharedPreferences
- 裁剪区域：SharedPreferences
- 音乐文件：APP 私有目录 `files/music`
- 音乐信息：SharedPreferences
- 生成视频：系统相册 `Movies/DouyinLocalMaker`

没有服务器，不上传商品截图、文字或音乐。

## Android 工程

- Kotlin
- `minSdk 29`
- `targetSdk 35`
- Android Media3 Transformer 用于本地视频合成
- WebView 用于打开商品链接

## 编译

### Android Studio

打开本目录，让 Gradle 同步完成后运行：

```bash
gradle :app:assembleDebug
```

APK 输出：

```text
app/build/outputs/apk/debug/app-debug.apk
```

### 没有本地 Android 编译环境

项目已经带了 `.github/workflows/build-apk.yml`。把项目放进 GitHub 仓库后，Push 到 `main/master` 会自动编译，并把 APK 作为 Actions Artifact 上传；也可以手动运行 `Build Android APK` 工作流。

## 使用说明

### 裁剪

- “截图并裁剪”：截图后手动选择区域，并记住这次区域。
- “快速截(上次区域)”：直接套用上一次裁剪区域。
- “重新裁剪”：对当前原始截图重新调整。
- 裁剪框内部拖动 = 移动画框；四角白点 = 改大小。

### 文字模板

模板会保存文字、位置、字号和旋转角度。主页面可选择或保存模板。

### 音乐

音乐库支持导入本地音频文件，也可以导入带音轨的视频文件作为媒体来源。生成时会从设置的开始时间播放，长度不足时循环补足视频长度。

> 技术上保存/提取媒体音轨不代表自动获得商业重复使用权；正式发布时请按素材授权情况使用。
